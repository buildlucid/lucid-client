# Lucid Client

Client side libraries for building fast, accessible websites. Each one works with your own markup and styles, and is set up with HTML attributes.

## Libraries

Each library is published as its own package on npm.

- [Catalyst](https://github.com/buildlucid/lucid-client/tree/master/packages/catalyst): A reactive UI library that connects HTML attributes to typed stores.
- [Forms](https://github.com/buildlucid/lucid-client/tree/master/packages/forms): Accessible forms that work without JavaScript and get better with it.
- [Carousel](https://github.com/buildlucid/lucid-client/tree/master/packages/carousel): A carousel built on CSS scroll snapping.
- [Cookie Controller](https://github.com/buildlucid/lucid-client/tree/master/packages/cookie-controller): Cookie consent with a banner, settings and consent gated scripts.
- [Speculate](https://github.com/buildlucid/lucid-client/tree/master/packages/speculate): Prefetch and prerender the pages your links go to.
